PROJECT DESCRIPTION
Chat Anonymizer is a local Windows desktop application for reviewing and
redacting secrets and sensitive information before sharing configuration files,
logs, support messages, and chat transcripts. Its GUI accepts pasted content
and multiple dropped files. JSON inputs can be conservatively repaired,
pretty-printed, and combined into a single document for review.

The shared detector considers field names, value formats, and surrounding
structure. It covers API credentials, passwords, cookies, session tokens,
private keys, and authentication in proxy and database connection strings.
It preserves ordinary boolean settings and unrelated configuration values.
Users preview the input and redacted output before copying or saving.
Detection is heuristic; we do not claim complete coverage of every secret.

PRIVACY AND PURPOSE
Submitted content is processed locally and is not uploaded for redaction.
The application operates on files and text selected by the user. It does not
scan network ports, exploit vulnerabilities, or bypass security controls.
Users choose when to export output. Some outputs, including reversible
replacement maps and warning-mode output, require care because they may
contain original sensitive data.
